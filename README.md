# Ich spreche Deutsch

Платформа для изучения немецкого с нуля: уровень A00 как восхождение на гору Брокен (1141 м).

- 50 видеоуроков с канала «Немецкий язык по плейлистам» с отметкой просмотра
- практика к каждому уроку: карточки, выбор перевода, письмо, сборка фраз
- интервальное повторение, словарь с цветом рода (der, die, das)
- тренажёры: артикли, числа, «Скажи вслух»
- мотивация: высота в метрах, хижины, костёр-серия, нашивки, сертификат на вершине

Сайт статический, без сервера и сборки: HTML, CSS и JavaScript. Прогресс хранится в браузере, его можно сохранить в файл.

Структура:
- `index.html` — страница
- `assets/js/data.js` — содержание уроков (слова, фразы, конспекты)
- `assets/js/app.js` — логика
- `assets/css/style.css` — стили
- `assets/fonts/` — шрифты Unbounded и Golos Text
